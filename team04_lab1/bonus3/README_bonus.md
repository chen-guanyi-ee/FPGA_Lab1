# Lab1 Bonus 說明

## 修改的檔案
- `Top.sv`：RNG 的 FSM（RUN/PAUSED，開機即自動開始跳動）、LFSR 隨機數產生、
  8 段固定頻率選擇、capture/record/max 邏輯、LED 顯示。
- `NEXYS_A7.sv`：新增 BTNL/BTNR/BTND 的 debounce、`SW[6:0]` priority encoder、
  把二進位轉成十進位兩位數送到 7 段顯示器、把 LED 接到 `Top` 的輸出。
- `Debounce.sv`、`Seven_Segment_Display.sv`、`Nexys-A7-100T-Master.xdc`：未修改，
  直接沿用（BTNL/BTNR/BTND、LED[15:0] 在原始 xdc 裡都已經有腳位定義）。

## 按鈕總覽

| 按鈕 | 功能 |
|---|---|
| BTNC | 重置（歸零所有狀態，速度回到中間） |
| BTNR | 暫停 / 繼續（同一顆切換） |
| BTNU | 頻率調快（往上一級） |
| BTND | 頻率調慢（往下一級） |
| BTNL | 抓取目前數字（capture） |
| SW[6:0] | 控制隨機數範圍上限 |

> ⚠️ **注意**：因為 BTNU / BTND 被拿去做調頻率，這個版本**不再有「按 BTNU 才開始搖」
> 這個原始題目要求的按鈕**。改成一開機（或按 BTNC 重置後）就自動開始持續跳動，
> 只能用 BTNR 暫停/繼續。如果評分會照課程投影片檢查這個規格，記得在報告裡註明
> 這個更動（把啟動鍵拿去做調頻率、改成開機自動啟動 + 暫停鍵取代原本的啟動鍵）。

## 功能對應

### 1. 七段顯示器：最大值｜紀錄｜即時抓取｜目前數字
8 位數的顯示器從左到右分成 4 組，每組 2 位十進位數字：

| 位置 (AN7..AN0) | 內容 |
|---|---|
| AN7, AN6 | 最大值 (max) |
| AN5, AN4 | 紀錄 (record) |
| AN3, AN2 | 即時抓取 (capture) |
| AN1, AN0 | 目前數字 (current，持續跳動中的數字) |

十進位轉換直接用 `value / 10`、`value % 10`（值最大到 63，兩位數就夠顯示，
不會超過 99，不需要額外做 mod/clamp）。

### 2. 開機自動開始 + BTNR 暫停 / 繼續
一離開重置（BTNC 放開），`Top.sv` 的 FSM 直接進入 RUN 狀態，數字立刻開始持續跳動，
用「目前選定的頻率」（見第 3 點）**不會自動變慢，也不會自動停止**：
- 正在跳動時按一下 **BTNR** → 進入 PAUSED，數字立刻凍結在當下畫面（連已經走到
  一半的倒數計時也一起凍結，不會歸零）。
- 再按一下 BTNR → 回到 RUN，從剛才凍結的地方**接續**往下跳（不會重新從頭開始）。
- 暫停時七段顯示器的小數點（DP）會亮起，當作視覺提示。

### 3. BTNU / BTND：切換 8 段固定頻率
用 **BTNU（調快）** / **BTND（調慢）** 在 8 個固定速度之間移動，會**卡在邊界**
（最快按 BTNU 沒反應、最慢按 BTND 沒反應，不會繞圈）。選定某個等級之後，速度就
固定維持在那裡，不會再自己變慢：

| freq_level | 大約更新間隔 | 說明 |
|---|---|---|
| 0 | ~500 ms | 最慢 |
| 1 | ~300 ms | |
| 2 | ~180 ms | |
| 3 | ~100 ms | **開機 / 重置後的預設值（中間速度）** |
| 4 | ~50 ms  | |
| 5 | ~20 ms  | |
| 6 | ~8 ms   | |
| 7 | ~3 ms   | 最快 |

這 8 個間隔值定義在 `Top.sv` 的 `delay_th` case 敘述裡，可以自行調整微調節奏。
BTNU / BTND 在任何狀態下（RUN / PAUSED）都可以按，新選的速度會在下一次畫數字時
立刻生效。

### 4. LED（反映目前選定的頻率，而不是時間流逝）
LED 顆數與目前選定的 `freq_level` 成反比（level 越小＝越慢＝LED 越多）：
```
num_leds = (8 - freq_level) * 2      // 16, 14, ..., 2
o_led    = 16'hFFFF >> (16 - num_leds)
```
- freq_level = 0（最慢）→ 16 顆 LED 全亮
- freq_level = 7（最快）→ 只有 2 顆 LED 亮

### 5. Capture / Record / Max（BTNL）
- 第一次按 BTNL：把「目前數字 (current)」存進「即時抓取 (capture)」。
- 再按一次 BTNL：先把舊的 `capture` 值搬進「紀錄 (record)」，
  再把新的「目前數字」存進 `capture`（等於每按一次就往後推一格）。
- `max`：只要新抓取的數字比目前 `max` 大，就更新 `max`；
  重置（BTNC）時 `capture / record / max` 都會歸零。
- Capture 可以在 RUN（跳動中）或 PAUSED（已暫停）狀態下按，皆會抓到當下顯示的數字，
  滿足「在滾動過程中抓取隨機數」的需求。

### 6. SW[6:0]：用開關控制隨機數的最大範圍
把 `SW[6:0]` 這 7 顆開關當作「最高位優先」的選擇器：只看被撥上去的開關裡面，
**編號最大**的那一顆，決定隨機數用幾個 bit（範圍就是 `0 ~ 2^N - 1`）：

| 撥上去的最高位開關 | 對應範圍 |
|---|---|
| 沒有任何開關撥上去 | 預設 0 ~ 15（原本規格） |
| SW[0] | 0（固定值，邊界情況） |
| SW[1] | 0 ~ 1 |
| SW[2] | 0 ~ 3 |
| SW[3] | 0 ~ 7 |
| SW[4] | 0 ~ 15 |
| SW[5] | 0 ~ 31 |
| SW[6] | 0 ~ 63 |

`SW[15:7]` 沒有使用。之所以把上限訂在 6 bit（0~63）而不是做到 0~99，是因為
`2^6-1 = 63` 保證小於 99，兩位數的七段顯示器可以完整顯示、不需要額外做
mod 100 或 clamp 的邏輯；如果做到 7 bit（0~127）就會超過 99，需要額外處理
「超過兩位數怎麼辦」，複雜度高很多卻沒有實質好處，所以選擇比較穩健的 6 bit 版本。

實作方式：`NEXYS_A7.sv` 用一個 priority encoder 把 `SW[6:0]` 轉成 3-bit 的
`range_bits`，送進 `Top.sv` 的 `i_range_bits`；`Top.sv` 內部用
`range_mask = (2^range_bits) - 1` 去遮罩 LFSR 的低 6 個 bit，
每次「畫出」新數字時直接套用，所以就算滾動途中臨時撥開關，下一次更新就會反映新範圍。

## 可以微調的參數（在 Top.sv 開頭）
- `delay_th` case 裡的 8 個常數：調整 8 段頻率各自對應的間隔時間。
- `freq_level_r` 重置值（目前是 `3'd3`）：決定開機後預設用哪一段速度。
